Privacy Policy

rclone — Personal Google Drive Backup

Effective date: November 17, 2026

This Privacy Policy describes how the personal rclone deployment described at this site accesses, uses, stores, and protects Google user data.

1. Scope

This is a private, single-user tool operated by the owner of the Google account it accesses. It is not offered as a public service, and no third-party users are authorized.

2. Google user data accessed

With the owner's consent, the app accesses the owner's own Google Drive data, including file names, folder structure, file metadata, and file contents. It also stores OAuth credentials (access and refresh tokens) issued by Google for the owner's account.

3. How the data is used

Google user data is used only to back up and synchronize the owner's own files between the owner's private server and the owner's Google Drive. It is not used for advertising, profiling, or any unrelated purpose.

4. Storage and security

OAuth credentials are stored on the owner's private server in a configuration file restricted to the owner (file mode 600). Backed-up file data is stored on the owner's private server and in the owner's Google Drive. Access to the server is limited to the owner.

5. Sharing and disclosure

Google user data is not sold, rented, or shared with third parties. No third-party analytics or tracking services are used on this site.

6. AI and machine learning

Google user data is not used to develop, improve, or train generalized AI or machine learning models.

7. Retention and deletion

Data is retained only as part of the owner's backup and synchronization setup. The owner can revoke the app's access at any time from the Google Account permissions page, and can delete the stored OAuth credentials from the server. Revoking access or deleting the credentials stops further access to Google Drive.

8. Limited Use

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Contact

Questions about this Privacy Policy can be sent to grenon000@gmail.com.
