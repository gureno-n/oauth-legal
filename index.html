rclone — Personal Google Drive Backup

A private, single-user backup setup.

This site provides information about a personal rclone deployment. The OAuth client described here is used only by its owner to back up the owner's own Google Drive files to a private server. It is not a public service, and there are no user sign-ups.

What it does

rclone authenticates with the owner's Google account and synchronizes or backs up files between the owner's private server and the owner's own Google Drive. No other Google accounts are accessed.

Data access

The app requests access to Google Drive solely to read and write the owner's own files for backup and synchronization. Google user data is not shared with third parties and is not used to train or improve generalized AI or ML models.
